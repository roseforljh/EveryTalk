# Agent file delivery

When a task selects an SSH server, deliver APKs, reports, and exports from that selected source. Use the `download` tool's expiring HTTPS link after confirmation. Do not attach these outputs to chat, upload them to R2, or use the EveryTalk preview proxy to serve them. If no selected source can serve the file, report that instead of falling back. Preserve the existing sync path for ordinary chat attachments.
