# 行内公式显示裁切修复记录

## 问题现象

聊天正文中的行内分式公式数据完整，但部分 Android 真机只显示分子和分数线，分母区域被截断。以下公式可以稳定复现：

```text
$\frac{\ln(37)}{37}$
$\frac{\ln(36)}{36}$
```

## 排查过程

第一轮排查将根因判断为正文固定行高不足，并尝试扩大公式所在段落的行高。Compose 布局探针显示，在 `16sp` 字号与 `24sp` 基础行高下，文本行已自动扩展至 `35px`，公式占位框高度为 `28px`。继续扩大段落行高没有改变真机显示效果，因此行高不足并非最终根因。

进一步检查确认：

1. MathJax 生成的 SVG 内容、尺寸和 `viewBox` 均完整。
2. 问题只发生在行内公式，独立块级公式显示正常。
3. 行内 SVG 使用 `ContentScale.FillBounds` 贴满占位框。
4. 部分 Oppo 硬件文本管线会裁切贴近行内子容器边缘的 SVG 下降区，分母恰好位于该边缘。

## 最终修复

行内公式布局增加垂直安全区：

1. SVG 占位框顶部和底部各增加 `0.25em`。
2. SVG 保持 MathJax 返回的原始高度，并在占位框中垂直居中。
3. 公式所在段落的行高同步纳入安全区高度，避免占位框与相邻行重叠。
4. 加载态和错误态保持原有尺寸与对齐方式。

该改动将公式内容从硬件裁切边界向内移动，同时保留原始宽高比和正文基线关系。
